# Coding Craft

Read [the craft method](references/method.md) and [the domain playbook](references/playbook.md) when this activity applies.

Apply only the relevant track and scale the process to the task. The user's brief, project canon, repository rules, and tool-specific workflows remain controlling. Do not load other craft domains unless the task crosses domains.

For substantial creation or revision: establish a compact brief, test the difficult part early, create the artifact, then make a distinct field-critic pass. Fix substantial findings and recheck until none remain, or explicitly report missing evidence. Do not spawn agents solely because this reference describes critic roles.

For a small change, apply the relevant principles without compulsory planning documents. Preserve editable sources and report actual validation and delivery status. No publication or spending authority is granted by this skill.
